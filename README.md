# Nika-Engine-1.7.2 (demo)
Лёгкий движок для создания визуальных новелл: быстрый старт, понятная структура сцен, поддержка диалогов, ветвлений, музыки, звуков, изображений и анимации. Подходит для инди-разработчиков и новичков.

Простые сцены: декларативный формат описания диалогов и ветвлений.
Поддержка медиа: изображения, фоны, музыка, звуковые эффекты, простая анимация спрайтов.
Сохранения и загрузки: автоматическое сохранение прогресса, слоты сохранений.
Настройки игрока: выбор языка, громкости, пропуска текста, автопрокрутки.
Локализация: отдельные файлы переводов для лёгкой поддержки нескольких языков.
Расширяемость: плагины/скрипты для кастомной логики .
